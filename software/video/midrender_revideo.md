## Notes

### 2026-08-06, from research

- Videos as code through TypeScript generator functions instead of React, with a core that has no dependencies.
- Use when: you want Remotion's model without its company license. MIT.
- `npm init @revideo@latest`. Headless `renderVideo()` split across workers, plus a React `<Player/>` for previews.
- A far smaller ecosystem than Remotion, so expect to write more yourself.
