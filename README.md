> **Where does a new entry go?** Kind at the file level, domain at the section level — `skills.md` groups UI/design and SEO internally rather than splitting. A domain only graduates to its own file when its tools span *several kinds* and *substitute for each other*, so no kind file can hold the comparison. Video qualified: a skill, three plugins, a CLI and a library all doing overlapping jobs. Most things won't.

> Snapshot: mid-2026. This ecosystem churns fast — check a repo's recent activity before installing, especially community entries. Treat every MCP server and skill as executable code you're granting access to: skim the source and scope credentials tightly.
