## Notes

### 2026-08-06, from research

- Semgrep's plugin: scans against thousands of rules, and the agent rewrites the code until the scan comes back clean.
- Use when: you want the rules enforced, not suggested.
- The standalone `semgrep/mcp` repo is deprecated. Semgrep's MCP server now ships inside the `semgrep` binary.
