## Notes

### 2026-08-06, from research

- 73 `DESIGN.md` files rebuilt from real brands' design systems. Put one in the project root and the agent builds matching UI.
- Use when: you want output that looks like Linear, Stripe, Vercel or Notion.
- Covers AI platforms (Claude, OpenAI, Mistral), dev tools (Cursor, Vercel, Raycast, Warp), SaaS (Linear, Notion, Figma), fintech (Stripe, Coinbase, Wise), consumer brands (Apple, Spotify, Nike), and a retro web set.
- Plain markdown, no tooling. Each file ships HTML previews of its colors, type and components. `DESIGN.md` started with Google Stitch.
