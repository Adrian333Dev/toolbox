## Notes

### 2026-08-06, from research

- A development method built as skills, meant to stop agents jumping straight to code.
- Covers: brainstorming, writing plans, executing plans, development by subagents, TDD, systematic debugging, verification before completion, asking for and receiving code review, git worktrees, writing skills.
- Order: brainstorm, worktree, plan, execution by subagents, TDD, review, finish the branch.
- `/plugin install superpowers@claude-plugins-official`. Also Cursor, Codex, Gemini CLI, Copilot CLI.
- Opinionated and heavy on process by design. Adopt it on purpose.
