## Notes

### 2026-08-06, from research

- Turns requirements into tasks with dependencies, subtasks and tags, then tracks progress.
- Use when: a project is too big for one context window and you want structure that lasts between sessions.
- `npm install -g task-master-ai` or `npx task-master init`. The MCP server runs with `npx -y task-master-ai`. Works with Cursor, Claude Code, Windsurf, VS Code, Roo.
- Overlaps `obra_superpowers.md`: both impose planning structure. Pick one.
