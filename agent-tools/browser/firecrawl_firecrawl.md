## Notes

### 2026-08-06, from research

- Scrape, crawl, search, map and extract at scale. Turns URLs into markdown, HTML, screenshots or JSON. An agent mode gathers data from a prompt.
- Use when: you want a page's content, not to click through it: research, ingestion, filling a dataset.
- Modes: `scrape`, `crawl` (a whole site), `map` (find a site's URLs), `search` (results with their page content), `batch scrape`, `extract`.
- Self-host under AGPL-3.0, or pay for the cloud at firecrawl.dev. `pip install firecrawl-py` or `npm install firecrawl`. Ships an MCP server.
- AGPL-3.0 matters if the self-hosted version goes inside a closed product.
