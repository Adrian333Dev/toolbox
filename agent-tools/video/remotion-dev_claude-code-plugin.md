## Notes

### 2026-08-06, from research

- Remotion's own skills for writing Remotion code. Not a production pipeline.
- Use when: writing a Remotion project by hand and you want the agent to stop inventing APIs.
- `claude plugin marketplace add remotion-dev/claude-code-plugin`, then `claude plugin install remotion@remotion`, then restart Claude Code. Run `/remotion-best-practices`.
- The repo has no docs. They live at remotion.dev/docs/ai/claude-code-plugin.
